# Financial News Sentiment Classifier
A tool to classify news sentiment.

## GOAL
This project's purpose is to be able to classify news into three different category: positive, neutral, or negative (bullish, neutral, bearish).

It doesn't work as market predictions, it will only show what investor would think of the news.
